# portfolio

Personal site. Next.js (App Router), TypeScript, Tailwind v4.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

All content lives in `src/lib/content.ts` — work, projects, stack, links.
The resume PDF is `public/michael-wong-resume.pdf`.

Colors are CSS variables in `src/app/globals.css` (light + dark via
`prefers-color-scheme`).
